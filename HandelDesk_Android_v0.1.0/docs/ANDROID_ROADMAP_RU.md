# Android roadmap

## v0.1 alpha — текущий
Каталог, Snapshot, offline DB, поиск, карточка, донор, Quick Replace, категории/производители, базовые Options, Work Queue, Validation, ChangeSet, Preview/Apply, image cache.

## v0.2
- новые фото: Камера / Галерея / Файл (без OCR/сканирования);
- local content-addressed image store;
- отдельная image upload queue;
- главное фото / порядок / удаление;
- полноценный Add/Edit Options и Attributes по Bridge schema;
- Related Products.

## v0.3
- Find & Replace как desktop v0.5;
- configurable Validation Rules;
- Specials / Discounts;
- multi-language editor;
- рабочие Sessions и полноценный Work Queue Next/Previous;
- Undo/Redo.

## v0.4
- HDO v2 совместимый import/export;
- backup/recovery;
- Conflict Resolution UI для BASE / LOCAL / SERVER;
- selective Prepare Offline.

## v1.0
- стабилизация на реальном каталоге;
- миграции БД;
- recovery после kill/reboot;
- финальный Audit;
- production APK.

Никаких функций сканирования/Barcode/OCR в roadmap не включено.
